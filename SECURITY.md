# Security Policy

## Supported Versions

Security fixes are handled on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub private vulnerability reporting when it is enabled for the repository. If it is not enabled, contact the maintainer through GitHub and ask for a private reporting channel.

Include:

- A clear description of the issue.
- Steps to reproduce it.
- The expected impact.
- Any suggested fix, if you have one.

Reports will be reviewed as soon as practical.
